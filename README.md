# block-fr-
Blocs FR est un plugin pour Roblox Studio qui permet aux créateurs francophones de programmer leurs objets de jeu par glisser-déposer à l'aide de blocs visuels inspirés de Scratch et entièrement en français, tout en générant automatiquement le véritable code Lua correspondant

se qu'il y a en plus des autre un constructeur de gui intergré 
un wiki intégré au pluggin

pour l'installer il faut que vous le glisser dans votre dossier pluggin sur roblox studio
(C:\Users\VotreNomPc\AppData\Local\Roblox\Plugins)
ou le télécharger sur la toolbox de roblox studio
(https://create.roblox.com/store/asset/96537126991006/BlocsFR)
